# Input data

`Boltzmann_Matano_CoAl.xlsx` is the raw data, including its original calculation columns and formula errors. Python reads the concentration observations and validates the annealing times; it does not use the erroneous derived coefficients. Positions are in μm, concentrations in wt% Al.

`reported_summary.csv` preserves the earlier user-reported means and Matano positions. They are a separate comparison, not outputs recalculated from this workbook.
